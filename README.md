# Customer Segmentation Project

## 📌 Project Overview

Customer Segmentation is a machine learning project that divides
customers into different groups based on their demographic
information and purchasing behavior.

This project uses Python and the K-Means Clustering algorithm
to identify customer groups, analyze purchasing patterns, and
understand customer preferences.

## 🎯 Project Objectives

- Identify different customer segments using clustering.
- Analyze customer purchasing patterns and preferences.
- Understand customer demographics and spending behavior.
- Visualize customer segments using charts and graphs.
- Generate insights to support targeted marketing strategies.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 Project Methodology

1. Create and prepare the customer dataset.
2. Perform Exploratory Data Analysis (EDA).
3. Select relevant customer features.
4. Standardize the data using StandardScaler.
5. Use the Elbow Method to explore the optimal number of clusters.
6. Apply K-Means Clustering to segment customers.
7. Evaluate clustering using the Silhouette Score.
8. Visualize customer segments and purchasing behavior.
9. Generate customer insights and export the results.

## 👥 Customer Segments

The project categorizes customers into four groups based on
their relative income and spending characteristics:

- **Premium Customers:** Customers with relatively high income
  and high spending scores.
- **Careful Spenders:** Customers with relatively high income
  and lower spending scores.
- **Active Spenders:** Customers with relatively lower income
  and high spending scores.
- **Budget Customers:** Customers with relatively lower income
  and lower spending scores.

These labels are simplified descriptions of the generated
clusters and do not necessarily represent real customer behavior.

## 📈 Key Features

- Customer clustering using K-Means.
- Analysis of customer demographics and purchasing behavior.
- Customer segment visualization.
- Cluster evaluation using the Silhouette Score.
- Export of customer segmentation results to CSV files.
